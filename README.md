## Hi there 👋

My learning goals for Phase 0

Overall goal
I am a product manager who has built and shipped a live product, ExamBuddie, mostly by learning as I went. I want to replace that patchwork with a proper foundation, so I can make better technical decisions, estimate work honestly, and talk to engineers in their own terms.

1. Linux
- Move around a server confidently from the command line: files, permissions, processes and logs.
- Read a production log and find the real cause of a problem without guessing.
- Why it matters to me: I once stopped the wrong process on my own machine by accident. I want to understand what I am running before I touch it.

2. Networking
- Explain in plain words how a request travels from a student's phone to my server and back: DNS, IP addresses, ports, HTTP and HTTPS.
- Understand proxies, firewalls and why some connections are blocked.
- Why it matters to me: my hosting provider blocked outgoing email and my rate limits treated every user as one person. Both were networking problems I could not name at the time.

3. Programming
- Read code well enough to follow what a feature does and spot where a bug is likely to be.
- Write small scripts to check data and automate repeated tasks.
- Why it matters to me: a product manager who can read the code asks sharper questions and writes clearer requirements.

4. Cloud computing
- Understand the building blocks: servers, storage, databases, regions, and how they are priced.
- Know the difference between temporary and permanent storage, and between a test environment and a live one.
- Why it matters to me: uploaded images once disappeared on every redeploy, and my test and live databases drifted apart. I want to design around these things up front, not discover them after launch.

5. DevOps
- Understand how code gets from a laptop to live users: version control, automated builds, testing, deployment and rollback.
- Learn how monitoring and alerts work, so problems are caught before users report them.
- Why it matters to me: on ExamBuddie every push goes straight to live users. I want to set up safer release steps and be able to explain the risk of each one.

What success looks like at the end of Phase 0
- I can sketch how ExamBuddie is hosted and explain each part to a non-technical person.
- I can sit in a technical discussion, follow it, and challenge an estimate or a design choice with good reasons.
- I can weigh cost, speed, reliability and security when choosing between technical options.
- I am ready for the next phase without needing the basics explained again.
